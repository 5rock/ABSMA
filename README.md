# 🎬 MovieLens ABSA — Aspect-Based Sentiment Analysis for IMDb Movie Reviews

> **B.Tech College Project** | IBM Internship Project | Sentiment Analysis | NLP

---

## 1. Project Title

**MovieLens ABSA** — An end-to-end Aspect-Based Sentiment Analysis (ABSA) system for IMDb movie reviews, with a full-stack web interface for movie discovery and review analysis.

---

## 2. Problem Statement

Traditional sentiment analysis classifies an entire review as positive or negative — but this is too coarse-grained. A movie review like *"The acting was brilliant but the plot was boring"* is overall mixed, yet each individual aspect carries a distinct sentiment.

The problem is: **How do we extract fine-grained, aspect-level sentiments from unstructured movie reviews?**

---

## 3. Objective

1. Extract **movie aspects** (acting, plot, cinematography, music, etc.) from IMDb reviews
2. Categorize each aspect into **11 predefined movie domain categories**
3. Assign **sentiment** (positive / negative) to each individual aspect
4. Build a **web interface** for interactive movie search and review analysis

## 6. Dataset

**IMDb Large Movie Review Dataset** (`stanfordnlp/imdb`)
- Source: HuggingFace Hub
- Training set: **25,000 reviews** (balanced: 12,500 positive + 12,500 negative)
- Test set: **25,000 reviews** (balanced)
- Labels: `0 = negative`, `1 = positive` (REVIEW-LEVEL only)

> ⚠️ **Important**: The IMDb dataset provides **overall review-level labels only**. It does NOT include gold-standard aspect-level annotations. All aspect-level predictions in this project are automatically generated by the ABSA pipeline.

## 7. Preprocessing

Located in `src/data_preprocessing.py`:

- Remove HTML tags (`<br/>`, `<p>`, etc.)
- Unescape HTML entities (`&amp;`, `&quot;`, etc.)
- Normalize whitespace
- Preserve punctuation and casing (important for NER)

---

## 8. Aspect Extraction Methodology

Located in `src/aspect_extraction.py` | **Step 4 (completed)**

### Step 1 — Actor/Person NER
- Uses `dslim/bert-base-NER` via HuggingFace Transformers
- Extracts `PER` entity mentions
- Filters BERT subword fragments (`##ill`, `##ryl Streep`)
- Deduplicates repeated person mentions
- SpaCy NER fallback if Transformer fails

### Step 2 — Movie Aspect Extraction
- SpaCy dependency parsing + noun chunk extraction
- Domain taxonomy matching across 11 categories:

| Category | Example Keywords |
|---|---|
| Actor/Performance | acting, performance, portrayal, cast |
| Plot/Story | plot, story, narrative, script |
| Ending | ending, finale, conclusion, climax |
| Direction | director, directing, vision, filmmaking |
| Cinematography/Visuals | cinematography, visuals, lighting, shots |
| Music/Soundtrack | music, soundtrack, score, background music |
| Dialogues/Screenplay | dialogue, screenplay, lines, monologue |
| Pacing/Editing | pacing, editing, runtime, transitions |
| Characters | character, protagonist, villain, depth |
| Special Effects/CGI | CGI, VFX, special effects, stunts |
| Atmosphere/Tone | atmosphere, mood, tone, vibe |

### Results (Step 4)
- 50 IMDb reviews → **542 aspects extracted**
- All 50 reviews contained at least one aspect
- Average: **10.84 aspects per review**

---

## 9. Sentiment Classification Methodology

Located in `src/sentiment_classifier.py`

**Approach**: TF-IDF + Logistic Regression

- **TF-IDF Vectorizer**: 50,000 features, unigrams + bigrams, sublinear TF scaling
- **Logistic Regression**: C=1.0, LBFGS solver, 500 iterations
- **Training data**: Full IMDb train set (25,000 reviews)
- **Test accuracy**: ~88-90%
- **Why this approach**: Trains in ~30 seconds on CPU, fully serializable, no model download required

## 10. Complete Pipeline

```
IMDb Review Text
       ↓
  clean_text()         ← HTML removal, whitespace normalization
       ↓
  AspectExtractor      ← BERT NER (actors) + SpaCy (movie aspects)
       ↓
  Aspect Categorization ← Domain taxonomy (11 categories)
       ↓
  SentimentClassifier  ← TF-IDF + LogReg applied to CONTEXT SENTENCE
       ↓
  ABSA Result          ← {aspect, category, sentiment, confidence}
```

## 15. Limitations

1. **No aspect-level ground truth**: IMDb labels are review-level only. Aspect-level sentiments are predictions, not evaluated against gold truth.
2. **Sentiment granularity**: Only binary (positive/negative) — no neutral class.
3. **Aspect quality**: Taxonomy-based matching may miss domain-specific vocabulary.
4. **BERT subword fragments**: Improved but may still appear in rare edge cases.
5. **Context window**: Sentiment is predicted on the context sentence, not on isolated aspect tokens, which may include surrounding sentiment not specific to the aspect.
6. **Movie metadata**: Genres, age categories, and Edge Ratings in `data/movie_metadata.csv` are manually curated application metadata — not sourced from IMDb.
