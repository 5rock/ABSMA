About MovieLens ABSA

B.Tech Final Project — NLP & Sentiment Analysis

Problem Statement & Objective

Traditional sentiment analysis classifies an entire review as simply positive or negative. However, movie reviews are nuanced—a viewer might praise the acting but criticize the plot. The objective of this project is to build an Aspect-Based Sentiment Analysis (ABSA) system that digs deeper by extracting fine-grained targets and predicting the sentiment for each specific aspect.

How it Works

  1. Text Preprocessing: Cleans HTML, normalizes text, and prepares sentences.
  2. Aspect Extraction: Uses HuggingFace BERT NER for identifying actors/entities and SpaCy for dependency parsing to find aspect terms.
  3. Categorization: Maps extracted terms into 11 movie domains (e.g., Cinematography, Direction, Plot).
  4. Sentiment Classification: A TF-IDF Logistic Regression model trained on IMDb reviews analyzes the local context sentence surrounding each aspect to predict sentiment.

System Architecture

This is a full-stack Flask application. The frontend communicates with the backend REST API. For the movie catalogue, the backend integrates with the IMDb API via AWS Data Exchange (with a local dataset fallback), ensuring real metadata, proper deduplication, and caching.

⚠️ Important Data Disclaimer

This is a demonstration application. Please note the following constraints:

  • IMDb Labels: IMDb provides overall review-level sentiment. The aspect sentiments shown in this app are automatically generated machine predictions, not gold-standard human annotations.
  • Metadata: Some movie metadata (like Edge Rating or Age Category) are custom application classifications used to demonstrate filtering, while ratings and plots are pulled from IMDb.

Technologies Used

Python 3 Flask SpaCy Transformers (BERT) scikit-learn Pandas IMDb API (AWS) Vanilla JS/CSS
